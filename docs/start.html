Offline installer

Get started

Open the Camemake installer. Same path on Windows and Linux, on an empty board or a board that already has images.

Open the tool

Windows: double-click CameVision-Single.exe (bundled Python).

Linux: open CameVision-Single or CameVision-Single.sh.

Or run CameVision-Single.cmd / python tools/cv_single_studio.py. The offline tool opens at http://127.0.0.1:8765/tool.html.

To rebuild this installer for another PC: python tools/cv_single_pack_offline.py.

USB

Maskrom

  1. Connect USB-C and power the board.
  2. Click Install USB driver.
  3. Hold BOOT, tap RESET, keep BOOT held.
Package

Install

  1. Select CameVision Ego Single Sensor · SC233HGS or · MIRA220.
  2. Click Install.
  3. Release BOOT when the board starts.

The package writes loader, env, idblock, U-Boot, boot, userdata, oem, rootfs, and the overlay.

Do not flash gen1 serial 0558fa189447bc45.

ADB

Open

  1. Click Open for http://127.0.0.1:8081/.
  2. Click Extended diagnostics for a full board dump.

Use the camera

1 · Camemake UVC USB webcam. Windows Camera, full resolution. No phone.
2 · Standalone Phone app over Bluetooth. Record to the card, send through the phone, clear the card, 10 s quarter-res preview.
3 · Server Phone app. Camera uploads over Wi-Fi to the server you set in Setup (starts as a template).

UVC: Camemake 2207:0016, MJPEG 1400×1600 / 1050×1200 / 700×800 / 350×400 at 60/30/15, plus the SD card as a drive. App: CameVision 0.1.
