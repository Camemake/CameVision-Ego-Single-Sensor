Offline installer

Get started

Open the Camemake installer. Same path on Windows and Linux, on an empty board or a board that already has images.

Open the tool

Windows: double-click CameVision-Single.cmd.

Linux: open CameVision-Single.sh.

Or run python tools/cv_single_studio.py. The offline tool opens at http://127.0.0.1:8765/tool.html.

To rebuild this installer for another PC: python tools/cv_single_pack_offline.py.

USB

Maskrom

  1. Connect USB-C and power the board.
  2. Click Install USB driver.
  3. Hold BOOT, tap RESET, keep BOOT held.
Package

Install

  1. Select CameVision Single.
  2. Click Install.
  3. Release BOOT when the board starts.

The package writes loader, env, idblock, U-Boot, boot, userdata, oem, rootfs, and the overlay.

Do not flash gen1 serial 0558fa189447bc45.

ADB

Open

  1. Click Open for http://127.0.0.1:8081/.
  2. Click Extended diagnostics for a full board dump.
