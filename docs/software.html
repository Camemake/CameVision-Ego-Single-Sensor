Software

Three ways to use the camera: USB Camemake UVC, the phone app in Standalone, or the phone app in Server mode. The PC flashes the board. The live page is a lab view, not a substitute for those three.

Three options

1 · Camemake UVC Plug USB. Windows Camera opens Camemake (2207:0016), MJPEG at full resolution. No phone. Mono / MIRA220 is 1400×1600 on every boot, any computer. Wi-Fi is not required.
2 · Standalone The CameVision app starts and stops a recording over Bluetooth. Full camera + IMU land on the microSD card. The phone copies the files and uploads them to the server you set in Setup. The card warns when it is nearly full. You can clear recordings from the app.
3 · Server Same app, same card files. The camera uploads over its own Wi-Fi to that server. The card is the buffer if the network drops. Setup holds the server URL. It starts as a template: https://server.example.com/camevision/v1.

Phone app: App and CameVision-App. Recorder: tools/camevision_agent.py. Server contract: android/server.template.json. Scan name contains CameVision + last 6 MAC hex digits.

Camemake UVC

After the camera is live, USB is a composite gadget: Camemake webcam plus the microSD as a drive. This binds on every reboot. Wi-Fi is only for Server mode.
