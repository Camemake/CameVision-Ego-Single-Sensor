Maskrom · empty board or already flashed

Flash

Hold BOOT, tap RESET, write every partition, then the overlay. USB stays ADB.

USB

Maskrom

  1. Connect USB-C and power the board.
  2. Install the USB driver (Windows: host/DriverAssitant_v5.14. Linux: host/linux/99-camevision-rockusb.rules).
  3. Hold BOOT, tap RESET, keep BOOT held.
  4. The port is Maskrom 2207:110f or Loader. After reset it becomes ADB 2207:0006.
Package

Install

Writes loader, env, idblock, U-Boot, the selected sensor’s boot FIT, userdata, oem, rootfs, then that overlay over ADB.

python tools/cv_single_flash.py --package camevision-single
python tools/cv_single_flash.py --package camevision-mono

Or double-click CameVision-Single.exe (bundled Python). Release BOOT when the board starts.

Shop sensors: SC233HGS, OG02C10, MIRA220, AR0235 (colour / mono), OX05B1S, Kaimou GS2.3. The two Maskrom kits in this tree are SC233HGS and AM / MIRA220.

Do not flash gen1 serial 0558fa189447bc45.

ADB

Open

python tools/cv_single_page.py

Forwards the on-board live page and IMU HUD, then opens a browser.

Where the images live

AM / MIRA220 is restore/release-1.1-mono-mira220-20261023 (boot camevision_boot_mono_wifi.img, Wi-Fi + BLE + Camemake UVC). Shared SPL / oem / rootfs: restore/known-good-20260819-camera-adb. Clone with Git LFS so the large images download.
