离线安装程序

入门

打开 Camemake 安装程序。Windows 与 Linux 相同。空板或已有镜像的板，步骤相同。

演示工具为英文界面。

打开工具

Windows：双击 CameVision-Single.exe。

Linux：打开 CameVision-Single 或 CameVision-Single.sh。

离线工具：http://127.0.0.1:8765/tool.html

USB

Maskrom

  1. 接上 USB-C 并供电。
  2. 安装 USB 驱动。
  3. 按住 BOOT，点按 RESET，继续按住 BOOT。
镜像

安装

  1. 选择 CameVision Ego Single Sensor · SC233HGS 或 · MIRA220。
  2. 点击 Install。
  3. 板子启动后松开 BOOT。

不要烧录 gen1 序列号 0558fa189447bc45。

ADB

打开

  1. 现场页 http://127.0.0.1:8081/
  2. IMU http://127.0.0.1:8083/

使用相机

1 · Camemake UVCUSB 网络摄像头。Windows 相机，全分辨率。不需要手机。
2 · Standalone手机应用走蓝牙。录像到卡，经手机上传，可清空卡。
3 · Server同一应用。相机用 Wi-Fi 传到 Setup 里的服务器。

UVC：Camemake 2207:0016，MJPEG 1400×1600 / 1050×1200 / 700×800 / 350×400，60/30/15，同时挂载 SD 卡。应用：CameVision 0.1。
