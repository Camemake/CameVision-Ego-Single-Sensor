使用相机

安装后有三种方式。后两种是手机应用（CameVision 0.1）。

1 · Camemake UVC 插入 USB，用 Windows 相机打开 Camemake。全分辨率。不需要手机。每次开机都会绑定，任意电脑可用，并挂载 SD 卡。
2 · Standalone 配对 CameVision + MAC 后 6 位。蓝牙录像到卡。经手机传到 Setup 里的服务器。
3 · Server 同一应用。相机用自己的 Wi-Fi 上传。把模板地址换成你的服务器。
