三种用法：USB Camemake UVC、手机应用 Standalone、手机应用 Server。现场页是实验室预览，不能代替这三种。

三种方式

1 · Camemake UVC 插入 USB。Windows 相机打开 Camemake（2207:0016），全分辨率 MJPEG。不需要手机。MIRA220 每次开机即为 1400×1600，任意电脑可用，不依赖 Wi-Fi。
2 · Standalone CameVision 应用通过蓝牙开始/停止录像。图像与 IMU 写在 microSD。手机把文件传到 Setup 里的服务器。卡快满时会提醒。可从应用清空录像。
3 · Server 同一应用、同一套卡文件。相机用自己的 Wi-Fi 上传。卡是断网缓冲。服务器地址在 Setup，初始为模板 https://server.example.com/camevision/v1。

手机应用：应用 与 CameVision-App。录像服务：tools/camevision_agent.py。扫描名称含 CameVision + MAC 后 6 位。

Camemake UVC

相机就绪后，USB 是复合设备：Camemake 摄像头 + microSD 磁盘。每次重启都会绑定。Wi-Fi 只用于服务器模式。
